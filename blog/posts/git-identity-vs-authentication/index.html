Git Identity vs Authentication: The Difference That Causes Most GitHub Problems

Part 2 of 5 29 Sep 2026 ·1 min read
gitgithubsshmental-models

One of the most common misconceptions in Git is assuming that your email address determines which GitHub account is used.

It doesn't.

Think of Git in three layers:

Layer 1: Commit Identity

git config user.name
git config user.email

This determines who appears as the author of a commit.

Layer 2: Authentication

SSH keys determine who GitHub believes you are.

For example:

ssh -T git@github-work

might authenticate as:

Hi work-username! You've successfully authenticated...

while:

ssh -T git@github-personal

authenticates as:

Hi personal-username! You've successfully authenticated...

Layer 3: Remote URL

The remote URL tells Git which SSH configuration to use.

For example:

git@github-work:company/repo.git

uses the work account, whereas:

git@github-personal:username/repo.git

uses the personal account.

Understanding these three layers makes troubleshooting Git issues dramatically easier and it's the foundation for the setup we'll build in Part 3.
