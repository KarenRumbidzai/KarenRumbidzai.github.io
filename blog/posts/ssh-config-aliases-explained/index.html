Understanding SSH Config Aliases for GitHub

Part 4 of 5 29 Sep 2026 ·1 min read
gitsshconfiguration

When developers first see a remote URL like this:

git@github-work:company/repo.git

they often ask: "Where did github-work come from?"

The answer is your SSH configuration file (~/.ssh/config):

Host github-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work

The alias github-work acts as a shortcut. Whenever SSH sees:

git@github-work

it automatically translates it to github.com, while forcing the use of the specified SSH key (id_ed25519_work).

This is the trick that allows multiple GitHub accounts to coexist on the same machine without conflicts — GitHub only ever sees one hostname, but SSH quietly swaps credentials based on the alias you used.
