How to Use Multiple GitHub Accounts on One Machine

Part 3 of 5 29 Sep 2026 ·1 min read
gitgithubsshtutorial

Managing personal and work GitHub accounts on the same computer can be frustrating if you rely on HTTPS authentication. A cleaner approach is to use separate SSH keys.

Step 1: Generate the Keys

ssh-keygen -t ed25519 -C "personal@email.com" -f ~/.ssh/id_ed25519_personal
ssh-keygen -t ed25519 -C "work@email.com" -f ~/.ssh/id_ed25519_work

Step 2: Create SSH Aliases

Add this to ~/.ssh/config:

Host github-personal
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_personal
    IdentitiesOnly yes

Host github-work
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_work
    IdentitiesOnly yes

IdentitiesOnly yes is important, it stops SSH from offering every key in your agent, which can cause GitHub to pick the wrong one.

Step 3: Configure Repository URLs

Personal projects:

git remote set-url origin git@github-personal:username/project.git

Work projects:

git remote set-url origin git@github-work:company/project.git

With this setup, Git automatically uses the correct account for each repository.
